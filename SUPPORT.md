# Getting help with moonbase

| You need | Go to |
|---|---|
| How to get started | [Docs: getting started](https://moonbase.cloud/docs/getting-started) |
| Connect moonbase to Claude, ChatGPT, Cursor and others | [Deploy from any AI chat](https://moonbase.cloud/docs/deploy-from-ai-chat) · connector address `https://app.moonbase.cloud/mcp` |
| Something is not working | [Troubleshooting](https://moonbase.cloud/docs/troubleshooting) |
| Is moonbase up? | [Status](https://moonbase.cloud/status) |
| What changed | [Changelog](https://moonbase.cloud/changelog) |
| Help with your account or a mission | [Support](https://moonbase.cloud/support) (sign in first) |
| Anything else | [Contact](https://moonbase.cloud/contact) or [contact@moonbase.cloud](mailto:contact@moonbase.cloud) |
| A security issue | [SECURITY.md](SECURITY.md). Please don't post it publicly |

GitHub issues in our public repositories are for problems with those repositories (for example, a wrong fact in the Skill). For your account, billing or a specific mission, please use Support, so we can look at it privately.
