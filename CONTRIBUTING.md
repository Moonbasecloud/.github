# Contributing to moonbase

Thanks for your interest in moonbase.

## What is open

All public repositories in this organization welcome issues, including [moonbase-skill](https://github.com/Moonbasecloud/moonbase-skill), [moonbase-examples](https://github.com/Moonbasecloud/moonbase-examples) and [moonbase-deploy-action](https://github.com/Moonbasecloud/moonbase-deploy-action). The moonbase product itself is closed source: its code is not on GitHub and we do not take outside code contributions to it.

## Issues

- **Bug or wrong fact?** Open an issue in the repository it belongs to, using the bug report form.
- **Idea?** Use the feature request form.
- **Help with your account or a project?** That is a support question. See [SUPPORT.md](SUPPORT.md).
- **Security problem?** Do not open an issue. See [SECURITY.md](SECURITY.md).

## Pull requests

We don't accept outside pull requests. If something in a repository is wrong or missing, please open an issue instead and we'll fix it.

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) in issues and discussions.
